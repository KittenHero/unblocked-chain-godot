# Revisiting a beat em up game after severely underestimating the scope

Last time we tackled this project in a game jam, we severely underestimated the amount of work it to to make this style of game.  While we were happy with the progress that we've made during the game jam, many of it's features remained unfinished and unpolished.  Our original plan involved a comic style narrative, multiple bosses and building up combos to gain power ups.  Wheter it was due to lack of experience, time or familiarity as a team, we were only able to implement a fraction of what we planned, and had very little testing.   During this month, we're coming back to revisit this project, and hopefully improve the game and make it feel a little more complete.
